# North Texas Maps — Coverage Index

**Read this file first** before opening any map PDF here. Each map file is 3–60 MB, so use this
table to pick the ONE map that covers the place you care about, then open only that file
(`read_document` for text/roads, or render a page and `analyze_image` it for the visual map).

Home base: **Anna, TX** (Collin County). Two levels of detail:

- **Street level** — USGS US Topo 7.5-minute quads (1:24,000): every road, labeled, over an aerial
  photo base, with contours, water, and railroads. Each quad covers ~6–7 miles E–W by ~8.5 miles N–S.
- **Regional level** — TxDOT county + district maps: every road at a wider scale, best for planning a
  route between towns or **out of the region** (egress). Not aerial; clean road-map style.

| File | Covers | Use it for |

| `txdot_collin_county.pdf` | **All of Collin County** (Anna, McKinney, Frisco, Plano, Prosper, Celina, Melissa, Wylie…) — every county and local road | Getting anywhere inside the home county |

| `txdot_paris_district.pdf` | **TxDOT Paris District:** **Grayson** (Sherman/Denison), **Fannin** (Bonham), **Hunt** (Greenville), Lamar (Paris), Delta, Hopkins, Rains, Red River, Franklin counties | The north/northeast route to the **Oklahoma border** and east toward Paris, TX |

## Honesty about coverage
- **Street level** is guaranteed only for the **Anna→Collin cluster** and the **Anna→Sherman→Red River
  corridor** (the quads above). Elsewhere in DFW, use the **TxDOT district maps** — they show every road
  but at a wider (non-aerial) scale, which is enough to plan a route, not to see individual driveways.
- For turn-by-turn street detail anywhere else in the US with no internet, install an offline map app
  (**OsmAnd** / **Organic Maps**) and download its OpenStreetMap data **before** an outage.

**Licensing:** USGS US Topo quads are US-government public domain; TxDOT county/district maps are Texas
state public records. Included for offline emergency reference.
