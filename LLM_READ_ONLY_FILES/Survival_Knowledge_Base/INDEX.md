# Master Index — Survival Knowledge Base

Every topic guide, grouped by need. Each guide is deep, self-contained, and beginner-friendly. Start with a guide's **"Read this first"** section, then read on for full detail. See [README.md](README.md) for how to use this set (as a person or with an offline LLM) and [COVERAGE.md](COVERAGE.md) for status.

> 🚨 **In an emergency, open [START-HERE.md](START-HERE.md) first** — a 60-second triage for immediate life threats and a "pick your situation" router to the right guide.
